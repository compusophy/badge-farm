# 🏆 badge farm

a repo dedicated to unlocking github profile achievement badges.

## badges targeted

| badge | status | tier |
|---|---|---|
| 🤠 quickdraw | ⏳ | one-time |
| 🤪 yolo | ⏳ | one-time |
| 🦈 pull shark | ⏳ | bronze (16 PRs) |
| 🧠 galaxy brain | ❌ needs help | base (2 accepted) |
| ⭐ starstruck | ❌ needs stars | base (16 stars) |
| 👯 pair extraordinaire | ❌ needs co-author | base (1 co-authored) |

## how it works

each achievement has specific triggers on github. this repo exists to systematically
activate those triggers through legitimate repository activity.

## achievements guide

### quickdraw 🤠
> close an issue or pull request within 5 minutes of opening it

### yolo 🤪  
> merge a pull request without a code review

### pull shark 🦈
> get pull requests merged (2 = base, 16 = bronze, 128 = silver, 1024 = gold)

### galaxy brain 🧠
> have your discussion answers marked as accepted (2 = base, 8 = bronze, 16 = silver, 32 = gold)

### starstruck ⭐
> create a repo that gets stars (16 = base, 128 = bronze, 512 = silver, 4096 = gold)

### pair extraordinaire 👯
> co-author merged pull requests (1 = base, 10 = bronze, 24 = silver, 48 = gold)
